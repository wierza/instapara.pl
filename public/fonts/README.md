# Czcionki

Strona używa dwóch czcionek z płatną licencją, których nie można rozpowszechniać w repozytorium:

- **TAN Mon Cheri** → `public/fonts/TAN-Mon-Cheri/TAN-MON CHERI-Regular.woff2`
- **Cy Grotesk Key** → `public/fonts/Cy-Grotesk-Key/cy-grotesk-key-regular.ttf` i `cy-grotesk-key-bold.ttf`

Żeby zbudować projekt, umieść tu własne licencjonowane pliki pod tymi nazwami albo podmień czcionki w `src/app/layout.tsx` (np. na darmowe z Google Fonts przez `next/font/google`).
